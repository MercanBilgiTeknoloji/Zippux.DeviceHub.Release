# Zippux.DeviceHub.Release

DeviceHub’ın Windows kurulum paketleri burada yayımlanır. `DeviceHub-setup-<version>.exe` dosyasını ilgili sürümden indirebilirsiniz. [Yayınlar](https://github.com/MercanBilgiTeknoloji/Zippux.DeviceHub.Release/releases)

Standalone DeviceHub, güncellemeleri `main` dalındaki kanal manifestlerinden kontrol eder.

- [Stable](manifests/stable.json) kararlı sürümleri gösterir.
- [Beta](manifests/beta.json) ön sürümleri gösterir.

Manifestteki `version: null`, kanalda henüz yayın olmadığını gösterir.
