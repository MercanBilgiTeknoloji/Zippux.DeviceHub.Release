# Zippux.DeviceHub.Release

Tüm DeviceHub Windows kurulumları [Yayınlar](https://github.com/MercanBilgiTeknoloji/Zippux.DeviceHub.Release/releases) sayfasındadır. İlgili release’ten `DeviceHub-setup-<version>.exe` dosyasını indirin.

[releases.json](manifests/releases.json) sürüm manifestinde `latest` en yüksek sürümü, `latestMinor` en yüksek `X.Y.0` sürümünü gösterir. Ara sürüm güncellemeleri açıksa cihaz `latest` değerine bakar. Bir değer `null` ise o grupta henüz uygun yayın yoktur.
